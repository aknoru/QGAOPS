# References

`references.bib` contains the citation records used by the documentation.
`paper_manifest.csv` records provenance, retrieval status, and direct links.
The supplied PDFs are archived in `references/pdfs/` as local project inputs.
Third-party copyright and license terms must be checked before publishing or
redistributing them. The manifest marks which files were actually supplied
and reviewed. `NR` denotes not reported.
