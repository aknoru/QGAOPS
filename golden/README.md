# Golden Test Vectors Catalog
# [GOLDEN] [VALIDATION] Deterministic Test Vectors for RTL Golden Reference

This directory contains deterministic golden vectors generated by `scripts/generate_golden_vectors.py` (or `python -m qgpu generate-golden`).

## Directory Structure

* `spatial_ga/`: Golden vectors for 3D Euclidean Geometric Algebra $G(3,0,0)$.
  * `gp_scalar_scalar.json`: Scalar multiplication.
  * `gp_e0_e1.json`: Basis vector exterior product $e_0 e_1 = e_{01}$.
  * `gp_e0_e0.json`: Basis vector contraction $e_0^2 = 1$.
  * `rotor_multiply.json`: Composition of two rotors.
  * `rotor_sandwich.json`: Rigid rotation $R x \widetilde{R}$.
  * `gp_multivector.json`: General multivector product.
* `cga/`: Golden vectors for Conformal Geometric Algebra $G(4,1,0)$.
  * `cga_point_embedding.json`: Point embedding into null cone.
  * `cga_inner_product.json`: Distance metric inner product $P \cdot Q$.
* `quantum_ga/`: Golden vectors for Quantum-GA operations in $Cl(3,0)$.
  * `gate_x.json`, `gate_y.json`, `gate_z.json`, `gate_h.json`, `gate_s.json`, `gate_t.json`.
  * `h_on_zero.json`: $|0\rangle \to H \to |+\rangle$.
  * `bell_state.json`: $|00\rangle \to H \otimes I \to \text{CNOT} \to |\Phi^+\rangle$.
* `fixed_point/`: Fixed-point quantization comparison vectors.
  * `fix16_gp.json`: Float32 vs FIX16 $Q1.14$ geometric product with error bounds.

## Schema

Each JSON vector contains:
```json
{
  "test": "name",
  "description": "text",
  "input_a": { ... },
  "input_b": { ... },
  "expected_float32": { ... },
  "expected_fix16": { ... },
  "notes": "[GOLDEN] ..."
}
```
