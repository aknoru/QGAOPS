# Stage acceptance criteria

## Stage 1

All available source files are inventoried; requirements and source gaps are
explicit; literature records have provenance, citation keys, access status,
and comparison dimensions; research gaps are hypotheses rather than results.

## Stage 2

Basis masks, metric, product signs, operations, scalar-grade conventions,
fixed-point encoding, rounding, saturation, overflow reporting, examples, and
independent algebraic checks are unambiguous and hand-checkable.

## Stage 3

The documented tree exists; scripts run offline; citations are internally
consistent; Mermaid source is structurally validated; planned components are
clearly marked; no implementation or hardware result is represented as
complete.
